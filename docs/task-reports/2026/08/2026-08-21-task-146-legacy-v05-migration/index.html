TASK-146 · Migration

Legacy v0.5 → 1.x migration CLI

2026-08-21 daemon / CLI GH #208

What changed

Added a Grimoire v0.5 SQLite importer: littleimp migrate inspect|apply and POST /migrate/legacy/inspect|apply. Point at a v0.5 data/ directory (db.sqlite + user-uploads/), or a packed archive (.zip / .tar.gz / …). Multi-user databases require an owner; optional password verifies the v0.5 account hash. The supported source is v0.5 SQLite data or an archive of it; PocketBase-era backups are out of scope. No Grimoire 1.x login accounts were added.

Usage

  • littleimp migrate inspect --data-dir /path/to/grimoire/data
  • littleimp migrate apply --data-dir /path/to/grimoire/data --owner alice --dry-run
  • littleimp migrate apply --data-dir /path/to/grimoire/data --owner alice --yes
  • Optional: --password-file / LITTLEIMP_MIGRATE_PASSWORD
